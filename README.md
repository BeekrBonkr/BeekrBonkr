# Hi, I'm Michael

I learn something new every day, and most of it ends up as a tool I actually use — lately GNOME
Shell extensions for a multi-monitor Linux desktop, and before that a stack of Minecraft server
plugins and a couple of Discord bots. Everything here is free and open source.

## GNOME Shell

| | |
|---|---|
| **[Topbar Tweaks](https://github.com/BeekrBonkr/TopbarTweaks)** | A fully interactive top bar on every monitor, not a mirror — Activities, calendar, Quick Settings, and the tray icons and toggles other extensions add, on each screen. Bar position, size, colors, hide rules and animations are all configurable. |
| **[Always On Indicate](https://github.com/BeekrBonkr/AlwaysOnIndicate)** | Shows which windows are always on top or on every workspace: outlines, corner badges, a top bar menu, dock badges, shortcuts, per-app rules and a D-Bus interface for scripting. |
| **[gnome-toggle-window](https://github.com/BeekrBonkr/gnome-toggle-window)** | A small script that throws the active window to the other monitor on X11. |

Both extensions target GNOME Shell 48–50 and ship with a headless test harness that drives a
nested shell over D-Bus and takes its own screenshots.

## Minecraft (Paper / MBedwars)

| | |
|---|---|
| **[PracticeCore](https://github.com/BeekrBonkr/PracticeCore)** | A practice minigame plugin: bridging, bed breaking, rush, MLG clutching and a PvP bot that fights like a 1.8.9 player — every player in their own schematic-built arena, with millisecond timers and leaderboards. |
| **[Matchbook](https://github.com/BeekrBonkr/Matchbook-Releases)** | Persistent match history for MBedwars — every match saved with per-player stats and an event-by-event timeline, browsable in-game, exportable to CSV, on YAML or MySQL. |
| **[ExclusiveArenas](https://github.com/BeekrBonkr/ExclusiveArenas)** | Private, gated BedWars matches for MBedwars: party- or code-locked lobbies, an editable event timeline, shop overrides, match rules, saved presets, dozens of one-click host actions, and optional cross-server control through a shared database. |
| **[SkillRanks](https://github.com/BeekrBonkr/skillranks)** | Grants ranks from the numeric value of any PlaceholderAPI placeholder — independent rank trees, automatic checks, config migration. |
| **[VoteAddon](https://github.com/BeekrBonkr/VoteAddon)** | Per-arena votes for MBedwars: start the match early or kick a player, from a command or a lobby hotbar GUI. |

## Discord and odds and ends

- **[neo-gigabot](https://github.com/BeekrBonkr/neo-gigabot)** — a slash-command recode of my old
  all-in-one Discord bot: moderation, image commands, music with yt-dlp, per-server settings in SQLite.
- **[musicdisc](https://github.com/BeekrBonkr/musicdisc)** — a Discord music bot on discord.py.
- **[samba-share-man](https://github.com/BeekrBonkr/samba-share-man)** — a Windows HTA that connects
  you to a Samba share without opening a terminal.
